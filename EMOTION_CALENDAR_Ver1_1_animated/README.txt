# EMOTION CALENDAR Ver.1

## 起動方法
1. `emotion_calendar` フォルダを開きます。
2. `index.html` をブラウザで開きます。
3. 天気の自動取得を使う場合は、HTTPSまたはlocalhost環境で開き、位置情報を許可してください。

## 感情キャラクター画像の差し替え
`images` フォルダに次の名前で画像を入れてください。
- happy.png
- sad.png
- angry.png
- tired.png
- excited.png
- anxious.png
- surprised.png
- neutral.png

画像がまだない場合は、仮の絵文字が表示されます。
画像の参照場所は `script.js` 冒頭の `EMOTIONS` 配列です。

## 保存について
現在はブラウザの localStorage に保存します。同じブラウザ・同じ端末で利用するための初期版です。
設定画面からJSON形式で書き出し・読み込みができます。

## クラウド保存への拡張
一般公開時はSupabase等のデータベースと認証を追加する想定です。公開前にユーザー認証、アクセス制御、データ削除、プライバシーポリシーを整備してください。
この初期版にはクラウド同期・アカウント機能はまだ実装していません。

## 天気
Open-Meteo APIから現在地の現在の天気・気温を取得します。位置情報の許可が必要です。取得した値は保存ボタンを押したときに記録へ保存されます。

## Ver.1.1 追加内容
